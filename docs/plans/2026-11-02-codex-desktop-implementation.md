## 验收重点

1. 有效配置全部位于文档中心项目内，无全局模型、权限、MCP 或技能设置变更。
2. 旧规则不会要求新任务等待 pane、调用 report_route 或读取旧锁。
3. QA 的旧 attempt、其他任务证据、越界路径、缺失证据、失败命令、网络错误和控制台错误不能通过校验。
4. 正式摘要可进入版本管理；原始证据、客户表格、缓存和运行状态保持本地，原文件不被删除。
5. 新会话可从 CURRENT-ROUND、STATUS 和任务主记录恢复；不依赖已失效的子代理 ID。
