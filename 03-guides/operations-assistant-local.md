# 本地运营助手使用说明

运营助手作为管理后台全局悬浮聊天窗，主模型 `gpt-6.1-sol`，仅管理员和运营账号可用。支持商品、预售线索、测试申请和结构化问卷的只读查询与分析，不修改业务数据或发送邮件。

## 启动

本地 MySQL 使用 `127.0.0.1:3307/moxton_local`；若尚未启动，在 PowerShell 7 运行：

```powershell
& 'E:\moxton-ccb\runtime\local-db\20261103\start-local-db.ps1'
```

分别在两个终端启动后端与后台：

```powershell
Set-Location 'E:\moxton-lotapi'
npm run dev
```

```powershell
Set-Location 'E:\moxton-lotadmin'
pnpm dev
```

后台地址默认 `http://localhost:9527/#/home`，API为本机3033。登录后通过右下角的运营助手悬浮按钮打开聊天窗；助手不再有独立菜单项或 `/operations-assistant` 页面。使用已有管理账号登录本地数据库副本；线上数据库和生产配置不因本地登录改变。

桌面聊天窗为独立浮动卡片，默认约420×640：拖动顶部标题栏移动窗口，拖动右下角手柄调整大小，当前浏览器会保存位置和尺寸。窗口始终限制在可见区域；窄屏采用接近全屏的固定尺寸。点击右上角关闭或按 Escape 只隐藏聊天窗，重开后会话继续。

发送后立即显示右侧用户气泡与左侧助手查询状态，输入栏清空；查询完成后回答、统计和相关记录显示在助手消息下方。消息区独立滚动，输入栏保留在底部；失败时可重试。

后端开发 `.env` 的数据库指向本地；Agent 私有配置已在 `E:\moxton-lotapi\.env` 设置 `AGENT_ENABLED=true`、`AGENT_BASE_URL`、`AGENT_API_KEY`、`AGENT_MODEL=gpt-6.1-sol`。网关地址和密钥只由后端读取；不得写入前端变量或提交。`CLEANUP_JOB_ENABLED=false`，避免本地开发触发定时清理。`.env.production` 未修改，生产默认关闭，生产发布另行安排。

单轮后端总预算为180秒，后台客户端最多等待190秒；模型请求最多4次、工具执行最多6次。关闭聊天窗或切换后台业务页面不会取消进行中的请求；点击取消、登出、账号切换或失去助手权限会中止请求。

## 使用示例

- “统计最近7天预售线索的邮件状态，并区分线索数和提交次数。”
- “按地区统计澳大利亚待处理测试申请。”
- “查找羊群规模至少1000的测试申请，按规模排序。”
- “汇总问卷中最关注的产品和功能选项。”
- “查询fixture.customer@example.test的测试申请和详细地址。”（合成邮箱示例）
- “找出备注中希望回访的申请，显示联系方式。”

回答附后端计算的统计卡片、实际筛选条件、查询时间和可打开的业务记录。没有时间条件表示全部时间；分页/分组或引用被截断时会明确说明。历史空地区计为未知，跨产品重复提交会去重。

可以按姓名、邮箱、电话、牧场、地址、备注及问卷反馈查询当前账号有权查看的记录。必要客户信息可交给当前模型网关处理，实际字段显示为客户卡片，详细地址和备注按需加载。数据库文本中的指令按数据处理；无法核实的客户或统计回答回退为服务器摘要。助手继续只读，覆盖商品、预售、测试申请与问卷。

## 会话历史

历史仅保存在当前浏览器，按环境和登录账号隔离，保留7天、最近10个会话、每会话最近10轮。问题、回答、客户卡片、统计与筛选会持久化，刷新后可恢复；旧版本遗留的摘要仍需重新查询客户详情。可单独删除或全部清空；退出/换号会取消正在进行的请求并清空内存。浏览器存储不可用或容量不足时，当前页面会话仍可使用并提示刷新后可能无法恢复，不做跨设备同步。
