## 概述

### 问题陈述

邮件发送可能失败，运营需要在后台对某条预约记录重发优惠码邮件。重发必须使用原优惠码，不能生成新码。

### 解决方案

在预约优惠码列表和详情中增加“重发邮件”操作，调用后端重发接口，并刷新当前记录状态。

### 范围

**包含:**
- API service 增加重发接口。
- 列表或详情中增加“重发邮件”按钮。
- 二次确认。
- 成功后刷新列表/详情。
- 失败时展示错误。

**不包含:**
- 邮件服务后端实现。
- 预约名单页面基础搭建。
